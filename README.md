# 贪吃蛇

一款可以在电脑和手机浏览器里直接打开的贪吃蛇小游戏，也可以安装 Android 安装包（APK）。撞到墙壁或自己的身体就会结束，没有穿墙。

提供两种模式，开始前可在「经典模式」和「重力模式」之间切换，最高分分开记录。

## 玩法

控制小蛇吃掉红色果实。每吃一个，分数加 1，速度也会逐渐加快。撞到四周的墙壁，或咬到自己，游戏结束。最高分会保存在浏览器本地，下次打开仍然有效。

### 经典模式

用方向键、WASD、屏幕方向键或滑动来控制小蛇。

### 重力模式（重力贪吃蛇）

倾斜手机来控制方向。果实也会顺着重力一格一格滚动，碰到墙壁或小蛇的身体就会停住。第一次开始或点「校准」时，会把当前握持角度设为水平，避免必须把手机放平。棋盘左上角的气泡指示器会显示当前倾斜。

如果大约一秒内收不到倾斜感应（例如在电脑浏览器里，或未授权），会出现提示，此时仍可用方向键或屏幕方向键游玩；果实会顺着你最近选择的方向滚动。

## 操作

- 电脑：方向键或 `W` `A` `S` `D` 移动，空格键开始 / 暂停 / 继续
- 手机（经典模式）：屏幕下方的方向键，或在棋盘上滑动
- 手机（重力模式）：倾斜机身；也可点「校准」，或使用方向键作为备用
- 也可以点击「开始」「暂停」「重新开始」按钮

## 如何本地打开

这是一个纯静态页面，不需要安装依赖，也不需要打包。用浏览器直接打开 `www/index.html` 即可。

## Android 安装包

可以用 Android Studio 或本仓库中的 Gradle 工程打包调试版 APK。在已安装 JDK 21 和 Android SDK 的环境中，于项目根目录执行：

```bash
npm install
npx cap sync android
cd android && ./gradlew assembleDebug
```

生成的 APK 在 `android/app/build/outputs/apk/debug/`。首次在手机上安装时，需要允许「未知来源」或「安装未知应用」。

重力模式使用 WebView 自带的 `DeviceOrientationEvent`。Android 默认允许网页读取方向传感器，不需要额外权限或插件。
